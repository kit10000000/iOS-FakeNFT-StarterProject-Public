# Корзина

---

## Этап 1. Отображение корзины

Итог этапа: вкладка «Корзина» показывает список NFT из заказа, сумму и количество, есть индикатор загрузки, обработка ошибок и пустое состояние.

1. Добавить вкладку «Корзина» в `TabBarController` (иконка, заголовок) -  1 ч.
2. Создать модель `Order` - 0.5 ч.
3. Создать `OrderService` и добавить получение заказа — `GET /orders/1` - 1.5 ч.
4. Создать view рейтинга - 3 ч.
5. Создать каркас MVP для заказа - 2 ч.
6. Сверстать экран для заказа с использованием `UITableView` (в т.ч. нижняя панель) - 3.5 ч.
7. Создать ячейку `CartCell` для отображения NFT - 4ч.
8. Реализовать загрузку корзины: получить заказ, подтянуть детали каждого NFT - 4 ч.
9. Добавить индикатор загрузки и обработку ошибок - 2 ч.
10. Реализовать пустое состояние корзины - 1 ч.
11. Написать unit-тесты - 3 ч.

Итого: примерно 25.5 ч.

---

## Этап 2. Сортировка и удаление

Итог этапа: сортировка списка (по цене / рейтингу / названию) с сохранением выбора и удаление NFT через экран подтверждения.

1. Добавить кнопку сортировки и меню выбора - 2 ч.
2. Создать enum для сортировки, реализовать хранение в `UserDefaults` и восстановление после перезапуска - 2 ч.
3. Реализовать логику сортировки списка по выбранному критерию + сохранение выбора -  2 ч.
4. Добавить в `OrderService` логику изменение заказа с обновлённым списком `nfts` - 1.5 ч.
5. Сверстать экран подтверждения удаления - 4 ч.
6. Реализовать логику удаления: подтверждение, отправка запроса на сервер, обновление заказа, суммы и количества.  - 2 ч.
7. Написать unit-тесты для презентера (сортировка и удаление) - 2ч.

Итого: примерно 15.5 ч.

## Этап 3. Оплата

Итог этапа: полный сценарий оплаты — выбор валюты, пользовательское соглашение, оплата и обработка ошибки.

1. Создать модель `Currency`  -  0.5 ч.
2. Создать модель для результата оплаты - 0.5 ч.
3. Создать `CurrencyService` и реализовать запросы `GET /currencies` и `GET /currencies/{id}` - 3 ч.
4. Создать `PaymentService` и реализовать запрос для оплаты `GET /orders/1/payment/{currency_id}` - 3 ч.
5. Добавить логику очистки корзины - 1 ч.
6. Создать каркас MVP для работы с валютой - 2 ч.
7. Сверстать экран с валютами: `UICollectionView`  - 2 ч.
8. Создать ячейку `CurrencyCell` - 3 ч.
9. Реализовать логику загрузки валют - 1.5 ч.
10. Добавить открытие пользовательского соглашения через `WKWebView` - 1.5 ч.
11. Реализовать логику оплаты (экран подтверждения) - 2 ч.
12. Добавить обработку ошибки оплаты — алерт «Повторить» / «Отмена»  - 1.5 ч.
13. Написать unit-тесты презентера валюты/оплаты - 2 ч.
14. ПОлный прогон процесса оплаты на мок-сервере, README - 1 ч.

Итого: примерно  24.5ч.
